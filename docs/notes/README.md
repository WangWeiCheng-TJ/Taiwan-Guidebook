# 各城市待整理筆記

還沒整理進資料檔的想法、待確認事項，依城市分開記在這裡。之後有空再一起整理進 `data/`。

- [臺南](tainan.md)
- [臺北・新北](taipei.md)
- [彰化](changhua.md)

規則：

- 一律先記在這裡，不直接改 `data/`。
- repo 是公開的。店家和景點的推薦（口味、點什麼、值不值得去）可以記，也可以整理進 `data/`。
- 私人行程不記：出發日期、住宿、同行者、每天去了哪裡和心得。這些留在各自手機的旅行日誌（trip log），用來讓 AI 依自己的需求調整建議。
- 不是某個城市專屬的事項（app 功能、通用規則）記在 [../BACKLOG.md](../BACKLOG.md)。
