如何將此資料庫整合至您的網站或 App？

資料庫為開放標準 JSON 格式，可透過 GitHub Raw、CDN 或本機 API 隨時介接。

// 載入全部臺灣景點歷史資料
fetch('data/taiwan_attractions.json')
  .then(res => res.json())
  .then(data => {
    console.log(`已載入 ${data.attractions.length} 處歷史景點`);
    data.attractions.forEach(spot => {
      console.log(`[${spot.eras.join(', ')}] ${spot.name.en} - ${spot.summary.en}`);
    });
  });
